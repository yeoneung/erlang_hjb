# Erlang vaccination experiments

## Current experiments

The current code and saved results are in [`reproducibility/`](reproducibility/). See its README for instructions. The files described below are an earlier set of experiments.

Python code for switching-time optimization in an epidemic model with
Erlang-distributed infectious periods. The calculations use ODE integration
and scalar minimization on a CPU.

## Run

Use Python 3.12 and the pinned dependencies:

~~~bash
python -m pip install -r requirements.txt
python -X utf8 run_numerics.py
python -X utf8 run_validation.py --workers 4
python -X utf8 verify_results.py
python -X utf8 render_outputs.py
~~~

The numerical runs take several minutes. Paths are relative to the scripts,
so commands can be run from another directory using the script's full path.
Use `--workers 1` to limit parallel computation.

The two JSON datasets are included. To recreate the compact tables and
figures without rerunning the experiments:

~~~bash
python -X utf8 render_outputs.py
~~~

## Model

The state is `(S, I_1, ..., I_n)`, with `Y = sum(I_j)` and stage-transition
rate `mu = n*gamma`. The equations are

~~~text
S'   = -beta*S*Y - r*S
I_1' =  beta*S*Y - mu*I_1
I_j' =  mu*(I_(j-1) - I_j),  j = 2, ..., n.
~~~

Vaccination is off until a switching time `tau`, then runs at `r_max`.
The target is `S <= gamma/beta` and `Q <= epsilon`, where
`Q = sum((n-j+1)*I_j)`. Calculations also compare the target obtained by
replacing `Q` with `Y`, using the same family of single-switch controls.

Defaults are `r_max=0.03`, `epsilon=0.01`, `S0=0.99`, and `Y0=0.01`.
Uniform initial stages have `I_j(0)=Y0/n`. Parameters and tolerances are
defined near the top of the numerical scripts.

## Calculations

- `run_numerics.py`: stage-count sweep, four selected parameter sets,
  switching-time curves, backward adjoints, and post-entry trajectories.
- `run_validation.py`: switching grids with 161, 321, and 641 nodes;
  tighter ODE tolerances; first-stage, uniform, and last-stage initial
  infection; and a rebound comparison after vaccination stops.
- `verify_results.py`: re-evaluates saved hitting
  times, checks target entry, and compares refinement results.
- `render_outputs.py`: creates six LaTeX table fragments and three
  figures in both PDF and PNG format, at a width of 119 mm.

The baseline integrator is DOP853 with `rtol=1e-10`, `atol=1e-12`, and
`max_step=0.1`. Refinement uses `rtol=1e-12`, `atol=1e-14`, and
`max_step=0.05`. The validation search retains both endpoints and refines
each sampled local minimum. These are numerical minimization estimates.

`W` is the hitting time under immediate full vaccination. `V` is the
estimated minimum over switching times, and `tau` is the selected delay.
For the alternative `Y` target, `V` has the same restricted-control meaning.
Times use the units of the supplied rates.

## Data and outputs

`output/results.json` contains the main calculations.
`output/validation_results.json` contains refinement and sensitivity data,
trajectories, computation settings, and environment versions.
All data are generated by the deterministic model above.

Generated tables, figures, and the verification
report stay in `output/` and are ignored by Git. Compact figures and
tables are written to `output/rendered/`. The renderer leaves both JSON
datasets unchanged.
